One of the 7 slots the Tier-4 table missed. Every candidate below is UNDECIDED
in the curator; the deep-read pass finished with nine rivals harvested. All
replace/rework the 13 stones, so exactly one wins (visual layers excepted).

## How this decision actually resolves

It is downstream of the perk/magic ecosystem choice, same as the religion and
race slots: Simonrim suite -> Mundus, Enairim suite -> Andromeda, neither ->
pick by taste (Menhir for spectacle, Old Fashioned Birthsigns for classic-TES
feel, SSOO to stay near vanilla). Deciding the perks slot first makes this one
nearly automatic. Ryn's visual layer can be added regardless.
