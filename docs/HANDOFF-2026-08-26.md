## Standing rules (user directives, verbatim intent)

1. The build targets the latest game version. Any mod not updated for it gets
   rebuilt or remade from source.
2. Prefer open-source mods; record repo links in decision evidence.
3. Research before building: every build decision rests on definitive
   documentation (repo files, commit diffs, author statements).
4. Claims require receipts: a mod "works" only after in-game confirmation by
   the user, or a log/file artifact that proves the specific claim.
5. Screenshots are not allowed as an information source.
6. Ship a successful fix upstream to the author after user verification.
7. Kill ModOrganizer.exe before editing profile files (it rewrites
   modlist.txt/plugins.txt from memory on exit).
8. Edit MO2 profile/game config files with Python only.
9. Curation: filters reject, never select; keeps come from user review.
   "Ask Claude" batches get careful per-mod evaluation.

  `skse64_1_7_99.dll+0x420D0` in

  "Adventurer" (Skyrim Unbound.esp)` exists. RaceMenu's author publicly
  states SKSE 2.3.0 has broken Papyrus functions pending a fix
  (nexusmods.com/skyrimspecialedition/mods/19080 posts).

  Matches the author's public description of the engine regression.
