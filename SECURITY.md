# Security Policy

## Supported versions

Only the latest revision of the default branch is supported.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature. Please do not disclose a
checksum-bypass, unsafe path-handling issue, command-injection issue, or
publication-boundary failure in a public issue before a fix is available.

Reports should include the affected script, a minimal reproduction, expected
and observed behavior, and whether local game or mod files can be modified.
